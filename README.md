## Giới thiệu (Tiếng Việt)

Xin chào, mình là **Huỳnh Gia Pho**, lập trình viên Java Backend đến từ **Đà Nẵng**. Mình tập trung xây dựng hệ thống phía máy chủ với Java và Spring Boot: thiết kế RESTful API, làm việc với cơ sở dữ liệu quan hệ, đóng gói và triển khai ứng dụng bằng Docker, đồng thời luôn hướng đến code sạch, dễ bảo trì.

- Hoàn thiện đồ án tốt nghiệp và các dự án backend thực tế
- Thiết kế và xây dựng RESTful API với Spring Boot
- Thiết kế cơ sở dữ liệu và tối ưu truy vấn với MySQL, PostgreSQL
- Kiểm thử API bằng Postman, đóng gói ứng dụng bằng Docker
- Đang tìm hiểu sâu hơn về kiến trúc backend, bảo mật và cloud
- Sẵn sàng cho cơ hội thực tập và làm việc ở vị trí Backend Developer

## About me (English)

Hi, I'm **Gia Pho Huynh**, a Java Backend Developer based in **Da Nang, Vietnam**. I focus on building server-side systems with Java and Spring Boot: designing RESTful APIs, working with relational databases, and containerizing applications with Docker, always aiming for clean and maintainable code.

- Completing my graduation thesis and real-world backend projects
- Designing and building RESTful APIs with Spring Boot
- Database design and query optimization with MySQL and PostgreSQL
- API testing with Postman, containerization with Docker
- Exploring backend architecture, security and cloud technologies
- Open to internship and full-time Backend Developer opportunities
